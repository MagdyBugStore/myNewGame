# حروب الصليبيين — نسخة RTS بأسلوب Stronghold Crusader

لعبة استراتيجية وقت حقيقي **2D Isometric** شغّالة في المتصفح، من غير أي مكتبات خارجية
(Canvas 2D + JavaScript بس).

## التشغيل

افتح `index.html` في المتصفح مباشرة — أو شغّل:

```bash
npx serve .        # أو أي سيرفر ثابت
```

> **مهم:** `index.html` هو **ملف مبني (generated)** — المعاينة بتحمّل ملف واحد بس،
> عشان كده فيه خطوة build بتجمّع كل حاجة فيه.

## تعديل الكود ثم إعادة البناء

المصادر:

| الملف | المحتوى |
|---|---|
| `css/style.css` | شكل الـ HUD |
| `js/config.js` | الإعدادات + تعريف المباني والوحدات |
| `js/map.js` | توليد الخريطة + مسار A* |
| `js/buildings.js` | البناء، الإنتاج، الاقتصاد، التدريب |
| `js/units.js` | الفلاحين، الجنود، القتال، الطلقات |
| `js/ai.js` | قاعدة العدو + موجات الهجوم |
| `js/render.js` | الرسم Isometric + الخريطة المصغّرة |
| `js/input.js` | الكاميرا، التحديد، الأوامر، وضع البناء |
| `js/ui.js` | شريط الموارد، أزرار البناء، لوحة التحديد |
| `js/main.js` | التهيئة + الحلقة الرئيسية |

بعد أي تعديل:

```bash
node build.js      # بيجمّع كل الملفات في index.html
```

وبعدين حدّث الصفحة.

## التحكم

- **WASD / الأسهم** — حركة الكاميرا
- **عجلة الفأرة** — تصغير/تكبير (حول المؤشر)
- **زر أوسط + سحب** — تحريك الكاميرا
- **سحب بالزر الأيسر** — تحديد **الجنود فقط** (الفلاحين مش بيتاختاروا بالسحب — بس بنقرة مباشرة)
- **Shift + نقرة** — إضافة/إزالة وحدة من التحديد
- **زر أيمن** — أمر حركة / هجوم / جمع مورد
- **H** — إيقاف الوحدات المحددة
- **1…8** — أزرار البناء، **Esc** إلغاء، **C** الرجوع للقلعة
- **` (backtick)** أو زر **⌨ سكربت** — فتح وحدة التحكّم بالسكربتات
- **الخريطة المصغّرة** — نقرة للانتقال

## وحدة تحكّم السكربتات

اضغط `` ` `` أو زر **⌨ سكربت** فوق. اكتب أي جافاسكربت واضغط **Ctrl+Enter**.
الكود بينحفظ في `localStorage` ويشتغل تاني تلقائياً لو فعلت **تشغيل تلقائي**.
الكود بينفّذ في النطاق العام، يعني تقدر تلمس أي حاجة: `G.units`، `placeBuilding`، `queueUnit`…

### الواجهة `api`

| المجموعة | الدوال |
|---|---|
| معلومات | `time()` `res()` `pop()` `sel()` `me()` `foes()` `soldiers()` `workers()` `myB()` `foeB()` `keep(team)` `barracks()` `byId(id)` |
| أدوات | `nearest(from,list)` `dist(a,b)` `inRange(a,b,r)` `d(x,y,x2,y2)` `path(x,y,tx,ty)` `walkable(x,y)` `centerOf(o)` |
| أوامر | `moveTo(u,x,y)` `attack(u,target)` `stop(u)` `setOrder(u,{...})` `forEach(list,fn)` |
| بناء وتجنيد | `build(key,x,y)` `freeBuild(...)` `autoBuild(key,nearX,nearY,radius)` `canPlace(key,x,y)` `train(type)` `trainAt(barracks,type)` `queue(barracks)` `give({gold:1000})` |
| وقت وسلوك | `every(sec,fn)` `once(sec,fn)` `onWave((n,count)=>{})` `behavior(unitsOrFn,(u,dt)=>{})` `clearBehavior()` `clearAll()` `hooks()` |
| عرض | `log(msg)` `out(msg)` `center(x,y)` `zoom(z)` `help()` `G` (الحالة الخام) |

### أوامر الـ CLI (شريط الأوامر تحت)

اضغط `` ` `` → اكتب أمر + Enter. **أي سطر تاني يتنفّذ كجافاسكربت** (مثال: `api.res().gold`).
الأسهم ↑↓ بتلفّ تاريخ الأوامر، وعلامة **لايف لوجز** بتعرض رسائل اللعبة أوتوماتيك جوّا الـ output.

| الأمر | الوظيفة |
|---|---|
| `help [cmd]` | قائمة الأوامر + التفاصيل |
| `state` (`s`) | حالة اللعبة: وقت، موارد، سكان، جيش، موجات، كاميرا، FPS |
| `players` (`teams`) | اللاعبين: القلعة وصحتها، القوة، المباني، أقرب عدو لقلعتك |
| `logs [n]` (`l`) | آخر رسائل اللعبة (كل `logMsg` بيتسجل تلقائياً بالتوقيت) |
| `units [me\|foe\|soldiers\|workers\|wounded\|idle\|<type>]` | جدول الوحدات: id، نوع، فريق، موقع، صحة، نسبة %، حالة |
| `where <id>` | تفاصيل وحدة/بناية بالكامل + يحرّك الكاميرا ليها |
| `hp [id]` | الصحة — بدون أرقام = قائمة كل الجرحى |
| `buildings [me\|foe\|<type>]` | جدول المباني: موقع، حجم، صحة، نسبة البناء، العامل/الطابور |
| `at <x> <y>` | إيه موجود في بلاطة بالظبط (تضاريس/مورد/بناية/وحدات) |
| `map [x y w h]` | خريطة ASCII كاملة برموز (K قلعتك، k قلعته، @ وحداتك، X وحداته) |
| `sel` / `select <id\|soldiers\|workers\|me\|none>` | التحديد الحالي / تحديد بالمجموعة |
| `move <id\|soldiers\|workers\|all> <x> <y>` | أمر حركة |
| `attack <unitId> <targetId>` | أمر هجوم على وحدة أو بناية |
| `stop [group]` | إيقاف |
| `build <key> <x> <y>` / `build auto <key> [nearX nearY]` | بناء (بالظبط أو بحث تلقائي عن موضع) |
| `train <swordsman\|archer> [n]` | تجنيد |
| `give <res\|all> <n>` | إضافة موارد |
| `kill <id>` | تدمير وحدة/بناية |
| `ai` | حالة العدو: الموجات، قوته، أقرب وحدة ليك |
| `hooks` | المؤقّتات والسلوكيات المفعّلة |
| `center <x> <y>` / `zoom <z>` | تحريك/تكبير الكاميرا |
| `run <js>` | تنفيذ سطر كجافاسكربت |
| `clear` | تفريغ المخرجات |

### مثال: سلوك مخصص لكل محارب

```js
api.behavior(api.soldiers(), (u, dt) => {
  if (u.target) return;                                    // خليه يكمّل قتاله
  const e = api.nearest(u, api.foes());
  if (e && api.dist(u, e) < 7) api.attack(u, e);
});
```
> لو الكول백 رجّع `false` → الـ AI الافتراضي يتوقف للوحدة دي في نفس الإطار (يعني إنت اللي ماسكها بالكامل).

### مثال: تجنيد وبناء بمواعيد + استقبال الموجات

```js
api.every(5, () => {
  const b = api.barracks();
  if (b && api.res().food > 300 && b.queue.length < 3) api.train('swordsman');
});
api.onWave((n, count) => {
  api.log('موجة رقم ' + n + ' فيها ' + count + ' جندي', 'bad');
  api.center(32, 32);
});
```

> في الكونسول 5 أمثلة جاهزة (أزرار فوق المحرّر) تقدر تحمّلها بضغطة واحدة.

## حلقة اللعب

1. الفلاحين بيلتجمعوا أوتوماتيك: أكل من المزرعة، خشب من الشجر، حجر من الصخور، حديد من المناجم.
2. الذهب بييجي من ضريبة السكان والبيوت.
3. ابنِ **ثكنة** ودرّب جنود (سيف / رماة سهام).
4. **الموجات المعادية** بتيجي كل شوية — عدّاد فوق بيقوللك وقتها.
5. اهزم **قلعة العدو** عشان تكسب.
